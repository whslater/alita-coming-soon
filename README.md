# ALITA Aviation — Coming Soon

Static, responsive GitHub Pages website built with HTML, CSS and JavaScript.

## Publish
1. Create a public GitHub repository (e.g. `alita-coming-soon`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Visit `https://YOUR-USERNAME.github.io/alita-coming-soon/` after deployment.

## Before launch
- Replace the temporary text/CSS monogram with the approved ALITA logo asset.
- Replace the stylised SVG helicopter with licensed brand photography, if desired.
- Replace the placeholder `hello@alitaaviation.com` email with a working address.
- Review the marketing copy for services that are actually available.
- Add a custom domain via GitHub Pages settings and DNS when ready.

This is a static holding page. PHP/Twig, SQL, enquiry forms, and booking functionality will belong on the full website's PHP-capable hosting.
